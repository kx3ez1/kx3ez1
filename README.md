### 🚀 Projects & Highlights

#### ⚙️ Low-Level & Systems Programming
* **[server_1500](https://github.com/kx3ez1/server_1500)**  
  A fast, minimal, hot-reloadable HTTP server written in pure C11 using Linux kernel primitives (`epoll`, `mmap`, `seccomp`).
* **[ZetaDB](https://github.com/kx3ez1/zeta_db)**  
  Ultra-fast in-memory key-value database built for speed, safety, and reliability with Write-Ahead Logging (WAL) for crash recovery.

#### 🤖 AI & Automation Tools
* **[LLM Wrapper Telegram Bot](https://github.com/kx3ez1/llm_wrapper_telegram_bot)**  
  Production-ready Telegram bot leveraging Azure OpenAI endpoints with markdown formatting, concurrency, and password protection.
* **[Feehive Bruteforce](https://github.com/kx3ez1/Feehive-Bruteforce)**  
  Automated authentication utility integrating with Telegram bots for instant login status notifications.

#### 🌐 Full-Stack & Desktop Extensions
* **[Easy Com](https://github.com/kx3ez1/easy_com)**  
  Full-stack e-commerce architecture built with Next.js, Express, and Node.js.
* **[Spotify Clone](https://github.com/kx3ez1/spotify-clone)**  
  Music streaming web app built with React, TailwindCSS, and JioSaavn API integration.
* **[Custom Clock GNOME Extension](https://github.com/kx3ez1/custom_clock_gnome_extension)**  
  GNOME Shell extension displaying secondary timezone trackers and synchronized internet time.
